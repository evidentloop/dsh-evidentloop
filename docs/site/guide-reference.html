设置与常见问题

设置

设置按 Git 仓库保存，同一仓库的多个工作区共用。

设置 说明
自动审查 当前版本仅保存偏好，不自动触发；请手动发起审查
目标分支 对比的基准，默认是仓库的默认分支
扩展提示词 指定重点关注什么、严重程度怎么判，最多 20000 字
导出默认项 导出时的默认选项

隐私

  • 只读取仓库，不改动代码、暂存区和提交。
  • 审查用你在 DSH 里配置的模型；插件不接入其他外部系统。
  • 审查记录、处置与批注只保存在本机。

当前限制

  • 只审与目标分支对比的改动，不按单个 commit 审查。
  • 不处理合并请求、合并与暂存。
  • 暂不支持启用了 split index 的仓库；浅克隆需先补全历史。

常见问题

和代码审查插件有什么不同？ 先讲清这批改动做了什么、是否对上需求，再给出带证据的问题，并支持发回修改与留档。

审查结论可靠吗？ 每个问题都必须引用原文作为证据，核对不上的不展示。结论仍是 AI 的判断，请结合证据确认。

交付不见了？ 合并后会自动归档，在列表底部的「已归档」里。
