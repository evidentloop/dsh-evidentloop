# EvidentLoop P1 UX 交互规范 (Skill Rule)

本规范定义 DSH Desktop 评审台界面的工业级交互标准与视觉边界，所有修改必须无条件遵守。

## 1. 14 字准则
**清晰 · 优雅 · 美观 · 简洁 · 符合用户心智**

## 2. 顶栏规范（Workbench Toolbar）
- 工具栏为全局视图切换与筛选中枢，高度 48px，左右对称；
- 左侧依次为：`P.icons.fileTree` (文件树 16px) -> `[ 变更说明 | 文件对比 ]` -> `[ 全部文件 | 风险文件 | 新改动 ]`；
- 严禁在顶栏控件之间插播长文本（如「未通过校验」超链接文本）；
- 代码对比（Diff）视图下，校验告警占高为 0px，第 1 行代码顶格渲染；未校验说明沉淀于变更说明（Overview）正文卡片中。

## 3. 代码行追问规范（Gutter Sparkles Ask）
- 行号左侧按钮统一为 12px Lucide `Sparkles`（保留 `.annotation-add-btn` class 属性）；
- 点击行号 `[ ✨ ]` 直接提取连续变更块代码段（3~5 行），经 `maskSecrets()` 脱敏后带入会话草稿，并跳转至对话区；
- 严禁在 Diff 表格行内展开复杂的输入框、多余快捷胶囊或行内插入条。

## 4. 缺陷卡片与忽略交互（标杆基线对齐）
- 正常状态卡片零噪音标签（移除「有效问题」文本）；
- 底部操作栏统一为 14px 纯线性 Lucide 图标与 24px 高度热区：
  - `[ 💬 添加批注 ]`：打开底栏审定意见抽屉；
  - `[ ✨ 在会话中追问 ]`：携带缺陷详情跳转会话草稿；
  - `[ ⊖ 忽略 ]`：标记非问题。
- **标记非问题折叠**：标记后卡片折叠为 32px 单行轻量条（`> 逻辑 P2 · 一般 ... [已忽略] [恢复]`），不占用多行高度；
- **二次确认弹窗**：紧贴 `忽略` 按钮上方对齐，带向下小三角指示，严禁下沉遮挡下方源码行。

## 5. 出口安全与状态隔离
- 严禁任何未经 `maskSecrets()` 过滤的内容进入会话草稿或剪贴板；
- 目标会话状态可用性校验优先于草稿去重；
- 去重 marker 严格绑定目标会话，杜绝跨会话误判。
