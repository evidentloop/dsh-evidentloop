# 质量试验评分表

每次真实运行后由用户填写。结果与评分保存在方法目录之外，不影响 `promptVersion`。

| 项 | 1–5 分 | 说明 |
|---|---|---|
| 看懂速度 | | 看说明比自己读 diff 快多少；5 = 不看 diff 也能讲清这次改了什么 |
| 准确性 | | 说明与对齐有没有错误描述；5 = 没有错误 |
| 对齐价值 | | 是否指出了自己没注意到的未对齐或需求外改动；无需求依据时填「—」 |
| 噪声 | | 套话、重复、无用条目的多少；5 = 几乎没有 |

| 问题统计 | 数量 |
|---|---|
| 真阳性（确实是问题） | |
| 假阳性（不是问题） | |
| 其中 P0/P1 假阳性 | |
| 漏报（自己知道但没报出的） | |

建议准出线：3 次运行准确性均分 ≥ 4，且没有 P0/P1 假阳性。未达到时先改方法再复测。

记录项：冻结输入（`inputSha`）、方法版本（`promptVersion`）、模型与设置、原始 JSON、校验结果、以上评分。
